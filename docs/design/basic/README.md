# 基本設計

基本設計（構造仕様）は、どの部品が、どの値で、どう動くかを決める（設定の項目、状態遷移と判定の表、AI のセッションの起動の形、導入と点検の順番、テストの分け方）。
要件と ADR が「構造仕様（`docs/design/`）」と書いているのは、基本設計のこと。部品の中をどう作るか（`plugin/src/` のモジュールの分け方）は、[詳細設計][detailed]で決める。

## 読み方

- 設計の全体の読み方（根拠の示し方、用語、要件と ADR との関係、図の決まり）と、設計を変えるときの決まりは、[設計の README][design] にある
- 基本設計は、要件と ADR に従う。食い違っていたら要件と ADR が正しく、基本設計を直す
- 設定の項目の初期値と根拠は、[設定][b01]の表にまとめる。要件が決めた初期値は要件が正本で、表はその写し（ADR-20261018-005）。要件が決めていない初期値は表が正本。今の値の正本は設定ファイル（STRUCT-2）
- 節の図は `basic/diagrams/` に置き、文書の番号を頭に付ける（例：`02-run-flow.drawio.svg`）
